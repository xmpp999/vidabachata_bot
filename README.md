# Telegram-бот Vida Bachata

Бот для продажи билетов на вечеринки Vida Bachata.

## Возможности

- 📝 Регистрация с верификацией email
- 🎫 Продажа обычных (500 ₽) и парных (900 ₽) билетов
- 💑 Парный билет с поиском второго участника по @username
- 📱 QR-код для каждого билета
- 🛠 Админ-панель: создание событий, статистика, рассылка
- ⏰ Автоматическое закрытие продаж за N часов до события
- 📊 Отчёт на email админа (CSV)
